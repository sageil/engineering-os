# Evaluation

Evaluate three layers:

1. Triggering: the right skill loads and false triggers remain low.
2. Skill behavior: outputs satisfy the skill's governing gates.
3. Cross-skill behavior: one skill does not erase evidence, uncertainty,
   limitations, or scope established by another.

The most valuable cases test false assumptions, false positives, stale memory,
unnecessary planning, first-solution bias, and human-language quality.
