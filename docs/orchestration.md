# Orchestration

Use the narrowest skill set that changes the decision or reduces material risk.

- Unknown cause: engineering-investigation, then engineering-debugging.
- Material choice: engineering-decision and engineering-economics.
- Cross-cutting effects: systems-thinking or architecture-review.
- Risky execution: engineering-planning.
- Implementation: engineering-quality, with testing/refactoring as relevant.
- Incident: incident-response first; avoid ordinary implementation workflow until stable.
- Delivery: engineering-communication and adversarial-code-review.
- Durable lesson: learning-and-knowledge-capture and engineering-memory.

Skills must not blindly invoke each other. Activation follows the task and evidence.
