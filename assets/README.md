# Visual assets

Engineering OS uses a midnight navy background, thin contour lines, precise geometric forms, and a restrained cyan-to-violet palette with small coral accents.

## Current assets

- `engineering-os-hero.png` is the primary README hero and represents the skills as one connected operating system.
- `engineering-os-lifecycle.svg` is the horizontal lifecycle illustration used in the README.
- `engineering-os-overview.png` is the original overview poster retained as a visual reference.

The hero intentionally contains no embedded text.
The lifecycle embeds only stable conceptual labels, while installation details, skill inventories, and project behavior remain in Markdown so they are easier to update and review.
