# Evidence Model

Use these evidence classes consistently:

1. **Observed** — directly executed, inspected, or measured.
2. **Derived** — follows from verified code, types, constraints, or logic.
3. **Documented** — supported by authoritative documentation for the applicable version.
4. **Assumed** — plausible but unverified.
5. **Unknown** — insufficient evidence.

Claims must not outrank their evidence. Consequential actions require stronger evidence than reversible, low-impact actions.
