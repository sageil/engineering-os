# Evidence Model

- **Observed:** directly inspected, executed, or measured.
- **Derived:** follows from verified code, types, constraints, or logic.
- **Documented:** supported by authoritative documentation for the applicable version.
- **Assumed:** plausible but unverified.
- **Unknown:** insufficient evidence.

Do not report assumed or derived behaviour as observed. Never claim a command or
check ran unless it actually ran successfully.
