# Performance Review Reference

Load only when a credible constraint exists.

Establish the relevant scale, frequency, latency, memory, CPU, database, network, rendering, queue, or connection constraint.

Investigate asymptotic growth, repeated work, N+1 calls, unbounded reads, allocations, blocking paths, leaks, cache growth, concurrency, batching, and contention.

Prefer measurement. Do not recommend complexity for hypothetical scale.
