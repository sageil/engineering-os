# Concurrency and Distributed Systems Reference

Load when the change involves workers, queues, events, locks, retries, caches, leader election, or shared mutable state.

Review invariants under:

- duplicate delivery
- reordering
- delay
- partial failure
- concurrent execution
- retry after timeout
- lost acknowledgement
- stale reads
- process restart

Check idempotency, atomicity, ownership, fencing, bounded retries, backoff, jitter, dead-letter handling, observability, and recovery.
