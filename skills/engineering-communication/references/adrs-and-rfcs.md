# ADR and RFC Guide

## Architecture Decision Record

Include:

- Context
- Decision
- Alternatives considered
- Trade-offs
- Consequences

Keep implementation detail out unless it affects the decision.

## Request for Comments

Include:

- Problem and affected users
- Constraints and non-goals
- Proposed approach
- Alternatives
- Risks and unresolved questions
- Rollout and verification

Write to support a decision, not to showcase analysis.
