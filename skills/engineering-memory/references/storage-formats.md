# Storage Formats

Prefer concise, scannable entries.

## Minimal

- Title
- Scope
- Established date
- Source
- Rule or conclusion
- Why
- Use when

## Extended

Add only when warranted:

- Type
- Evidence
- Confidence
- Volatility
- Owner
- Supersedes
- Revalidate when
- Remove or promote when

Do not let metadata become more expensive than the knowledge it protects.
