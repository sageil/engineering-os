# Memory Types

Use this reference when choosing the shape and lifecycle of an entry.

- **Decision:** preserve context, rationale, alternatives, trade-offs, and revisit conditions.
- **Constraint:** preserve scope, cause, consequence, and expiry condition.
- **Lesson:** preserve reusable principle, trigger, and failure avoided.
- **Preference:** preserve only durable, explicit, correctly scoped collaboration preferences.
- **Exception:** preserve normal rule, deviation, justification, and removal condition.
- **Invariant:** prefer enforcement in code, schemas, tests, or automation.
- **Historical context:** retain only when needed to understand current choices.
- **Temporary state:** keep outside durable memory unless transition history is decision-relevant.
- **Open question:** keep in issues or investigation notes until resolved.
