# Pruning and Contradictions

When adding related knowledge, inspect the affected scope for:

- duplicate entries
- conflicting scopes
- superseded decisions
- obsolete exceptions
- entries missing rationale
- volatile facts without revalidation rules
- knowledge now enforced elsewhere

Resolve contradictions by comparing scope, authority, date, volatility, intended state, and live state. Update, narrow, merge, supersede, promote, or delete. Never leave two active entries that claim incompatible truths.
